Hermes-Agent
harness'ı baştan sona

Kendi Hermes modelleriyle birlikte tasarlanmış, kendini geliştiren (self-improving) bir tool-use ajanı. Bu deste; tool-call formatından öğrenme döngüsüne, dört çok-ajan paterninden context sıkıştırmaya kadar mimariyi gerçek kaynak kod üzerinden gezer.

agent/ · 128+ modül • tools/ · 40+ araç • Python + Node + Rust • 18 slayt

Ürün değil, model-harness ortak tasarımı

Claude Code bir üründür. Hermes ise açık bir ajandır ve harness, modelin eğitildiği trajectory formatını yayar — "prompt'a XML gömme" bir tercih değil, modelin fine-tune edildiği sözleşmedir.

03 — İmza #1 · tool-call formatı

XML-tagged JSON

Kalp burada. System prompt araçları <tools> içinde katalogar (XML registry); model <tool_call> içine JSON gömer.

// agent/agent_runtime_helpers.py
"You are a function calling AI model. ... within <tools> </tools> XML tags."
<tools>
  { ...her araç için JSON şema... }
</tools>
# sonuçlar <tool_response> içinde döner · reasoning <think> içinde

# model şöyle çağırır:
<tool_call>
{'name': read_file, 'arguments': {'path': 'a.py'}}
</tool_call>

Parse: _TOOL_CALL_TAG_NAMES (5 varyanta toleranslı regex) + başıboş kapanış temizliği.

08 — Context yönetimi

Production-grade sıkıştırma

Claude Code compaction'ının ağır versiyonu — atomik, kilitli, kurtarılabilir.

◆ Güvenli sıkıştırma

  • CompressionCommitFence — atomik commit; yarım kalırsa state geri sarılır
  • dağıtık kilit — eşzamanlı sıkıştırma çakışmasını önler
  • session rotation — gerekirse oturum döndürülür

◆ İnce ayar

  • context_references — büyük tool çıktıları referansa iner
  • context_breakdown — pencerede ne kadar yer kim tutuyor
  • executor saturation — sıkıştırma bir iş kuyruğu, timeout'lu

POC bağı: bizimki tek tool-mesajı granülerliğinde (fate + fayda-freni); Hermes tüm pencere düzeyinde (commit-fence).

11 — MAS · delegate_task

Subagent mimarisinin çekirdeği

◆ Her child alır

  • taze konuşma — parent geçmişi YOK
  • kendi task_id — kendi terminal + file cache
  • parent toolset'i eksi bloklu tool'lar
  • goal + context'ten odaklı prompt

◆ Sınırlar

  • parent yalnız çağrı + özeti görür (ara adımlar gizli)
  • recursive yok — child'tan delegate_task çıkarılır
  • MAX_DEPTH=1 düz; nested yalnız role="orchestrator"
  • steer / interrupt / spawn-pause canlı kontrol
DELEGATE_BLOCKED_TOOLS = {delegate_task, clarify, memory, send_message, cronjob}
# recursive yok · kullanıcıya sormaz · paylaşılan belleğe/zamanlayıcıya/platforma dokunmaz

13 — MAS · Kanban

Paylaşılan pano (blackboard)

14 — MAS · MoA + kıyas

Ensemble + felsefe ayrımı

◆ MoA — mixture-of-agents

/moa bir turn'ü ensemble yapar: referans modeller paralel danışman, ana model sentezler. Model-tool değil; loop tool-çağrısına sahip kalır. PII gizlilik filtresi var.

◆ Hermes vs Claude Code

Blackboard ailesi (Hermes): paylaşılan kuyruk + pano, doğrudan mesaj yok.

Mailbox ailesi (Claude Code teams): yerel-JSON inbox + doğrudan ajanlar-arası mesaj.

İki sistemin MAS felsefesindeki net ayrım: nereye yazıyorlar — ortak panoya mı, birbirinin posta kutusuna mı.
